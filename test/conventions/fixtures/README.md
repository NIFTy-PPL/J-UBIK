# CASA radio witness

`roundtrip_radio_obs.npz` is the original CASA-simulated observation,
thinned to every 15th integration (8 integrations, 3968 rows, 121,242 bytes).
It is not generated by jubik's forward model. The truth sky is rebuilt by
`radio_fixture.truth_hdu`; simulation and extraction instructions live in
`../mint/mint_radio_ms.py`.

Restored on 2026-09-17 from the frozen observation in commit `91f7a5f5`,
whose source SHA256 is
`41289d1b30d1dd748ca0fea0b623caa6231b83f58f70153fe4233c3e9d2879b9`.
Only rows were selected and the NPZ reserialized; no visibilities were
re-simulated. The resulting byte hash is pinned in `../conftest.py`.
Tests enforce a 150 kB limit. Keep the full MS, full observation, FITS images,
and output snapshots out of git.
